## Версия Java - 17  
Система сборки проекта – Maven  

### Команды  
```bash
java -jar read-file-app.jar --output=console — команда для ввода в консоль без сортировки
java -jar read-file-app.jar --output=file --path=output.txt — команда для ввода в файл без сортировки
java -jar read-file-app.jar --sort=name --output=console — команда для ввода отсортированных данных по имени в консоль
java -jar read-file-app.jar --sort=salary --output=console — команда для ввода отсортированных данных по зарплате в консоль
java -jar read-file-app.jar --sort=name --output=file --path=output.txt — команда для ввода отсортированных данных по имени в файл
java -jar read-file-app.jar --sort=salary --output=file --path=output.txt — команда для ввода отсортированных данных по зарплате в файл
java -jar read-file-app.jar --sort=asc --output=console — команда для ввода отсортированных данных в консоль по прямому порядку
java -jar read-file-app.jar --sort=desc --output=console — команда для ввода отсортированных данных в консоль по обратному порядку
java -jar read-file-app.jar --sort=asc --output=file --path=output.txt — команда для ввода отсортированных данных в файл по прямому порядку
java -jar read-file-app.jar --sort=desc --output=file --path=output.txt — команда для ввода отсортированных данных в файл по обратному порядку
```
